about=The MRF Translado GNSS plugin automates coordinate adjustment workflows according to Brazilian INCRA/SIGEF standards. It supports GNSS TXT import, coordinate translation using PPP IBGE or SIGEF Memorial references, integrated graphical visualization with satellite imagery, vector rendering between translated points, dynamic scale bar, HUD overlays, variance propagation, standardized TXT export, QGIS layer generation and professional PDF technical reporting. This version introduces a modern GIS-oriented interface with interactive map controls and advanced visual validation tools for georeferencing workflows.
